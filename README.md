## What it does

`main.py` (Python 3.13, standard library only) writes one joke about cats — a single line, under 200 characters — to `/output/entry.txt`:

> I asked my cat for emotional support. He sat on my keyboard, deleted my email, and purred like he'd fixed it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
